# GarrisonFarm 个人优化版v1.1

由 **轻骑可历#9000** 优化，在原项目 **1.2版本** 基础上优化。

原项目：[利用MAA自动刷取卫戍协议蚀刻章镀层](https://www.bilibili.com/video/BV1zMWZ6xED1/)

## 下载运行

在 [Releases](https://github.com/FJH3576/GarrisonFarm-Personal/releases/latest) 下载完整程序 ZIP，解压后运行 **开始刷角标.bat**。
完整运行库和 EXE 随 Release 提供，仓库中保存优化适配代码、启动脚本与两份说明。

1. 打开 MuMu 和明日方舟，设置 **1920×1080 横屏**，进入卫戍协议界面。
2. 按本机安装位置配置 `mumu_touch.json` 的 `emulator_path`；在 MAA 中确认能连接模拟器。
3. 首次使用可运行 **检查增强触控.bat**，然后运行 **开始刷角标.bat**。
4. 自选编队等操作见 [原版使用说明](使用说明.txt)。

## 优化内容

- 修复 `①` 等数字字符导致的整数转换异常。
- 通过 MuMu SDK 执行点击、滑动和干员拖动。
- 通过 MuMu SDK 快速获取游戏画面。
- 启动器过滤 SDK 坐标调试输出，保留正常运行信息。
- 保留原项目的购买、升级、部署及角标进度流程。

## 本机实测

MuMu **6.8.8.0**，1920×1080 横屏。一轮时长由 **24分钟缩短至13分钟**。

|---|---:|---:|
| 整轮时长 | 24分9秒 | 12分40秒 |
| 九回合准备合计 | 14分42秒 | 4分22秒 |

## 文件

- `mumu_touch.py`：增强触控和快速截图适配。
- `launcher.ps1`、`开始刷角标.bat`：启动与坐标调试输出过滤。
- `mumu_touch.json`：MuMu 路径、包名和增强功能配置。
- `settings.example.json`：MAA 路径配置示例。
- `strategies_done.example.json`：空白进度示例。
- 两份 TXT 说明分别保留原版使用说明和个人优化说明。
